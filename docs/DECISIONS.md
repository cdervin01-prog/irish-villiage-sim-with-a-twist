# Decisions

1. **C++20 utility selection plus constraints.** The brief supersedes the previous Unreal discussion. Three agents, no rendering. Duties/fatigue are enforced before optional utilities; shuffled initiative and cooldowns reduce forced chatter and ordering bias.
2. **SQLite as authoritative history.** Separate objective events and owner-scoped observations; stable string IDs and directional relationships. A full checkpoint includes RNG, profiles, needs, beliefs, schedules and lifetime dialogue attempts. Each step is one transaction. Exports are derived from the database. The live HTTP call holds the single-writer transaction open; acceptable for a three-agent single-process prototype, unsuitable for a concurrent service.
3. **One shared llama.cpp endpoint, separate prompts.** The HTTP API is OpenAI-compatible but runs locally. No global conversation history or sharing of private minds. One generation per selected turn, no model scheduling. JSON schema plus application validation, bounded response size/time, no redirects, default TLS validation, no fabricated fallback. Real runs use Qwen with thinking disabled.
4. **Minimal dependencies.** SQLite, nlohmann/json, libcurl and header-only doctest (equivalent to Catch2 for these tests). No spdlog requirement: JSONL already supplies structured records. The owner's awesome-cpp catalogue is a reference, not a reason to add libraries. No package manager hooks or automatic CMake network fetches.
5. **Research limits are explicit.** Traits/schedules are hand-calibrated. Private testimony is not truth. Recent-only memory retrieval and a numeric social appraisal are simple first hypotheses. No semantic verifier, belief evidence graph, fight mechanics or complete historical reconstruction. Preserve failures in evidence and propose a small next change rather than add villagers.
6. **Mock determinism versus real language.** Mocks are labelled fixtures with deterministic time identifiers, not purported emergent conversations. Model randomness/hardware can change real text; archive transcripts and server identity. Do not mix evidence categories.
